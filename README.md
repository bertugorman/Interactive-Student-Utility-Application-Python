# Python Control Flow Exercises (Week 8)

## 📌 Overview

This project contains basic Python exercises focused on control flow concepts such as:

* Conditional statements (`if / elif / else`)
* Loops (`for` and `while`)
* `break` and `continue`
* User input handling
* Simple problem solving

These exercises are designed for beginners to strengthen fundamental Python programming skills.

---

## 🧠 Tasks Included

### ✅ Task 1 — Basic If Statements

Takes temperature input from the user and prints a message based on the range:

* Freezing
* Cold
* Nice weather
* Hot

---

### ✅ Task 2 — Weekday or Weekend

Checks whether a given number (1–7) represents:

* Weekday (1–5)
* Weekend (6–7)

---

### ✅ Task 3 — For Loop Practice

Prints all even numbers from 0 to 20 using a `for` loop.

---

### ✅ Task 4 — While Loop Practice

Continuously asks the user for a password until the correct one is entered.

---

### ✅ Task 5 — break / continue

* Skips number 5 using `continue`
* Stops loop at number 8 using `break`

---

### ✅ Task 6 — Combined Mini Exercise

Asks the user for 5 numbers and counts:

* Positive numbers
* Negative numbers
* Zeros

---
